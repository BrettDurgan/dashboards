VII. Methodology Notes
Period: W41, Mon 10/05/2026 – Sun 10/11/2026, all 3 stores, 7/7 days real per store. Generated 2026-10-12.
Net sales: Each store's Net Sales = Σ totalBeforeTax on non-void transactions with returns netted in (Brett, 2026-09-28: standard at every store), deduped by transactionId, from self-pulled Dutchie exports (Pull-DutchieWeek.ps1). Network Net Sales is a straight sum across the 3 MA stores.
Labor: Worked Hours = real W41 UKG DetailedHours punches filtered by EIN AND Retail Department Full Path (Step 12) — every week uses its own hours (Brett, 2026-10-12). Payroll Cost = those hours × W40 DetailedRates (10/01 raises applied) [EST], because Sarah was out and no W41 Counters/Rates exist; one Springfield new hire (no punches yet) estimated from his sales. Salaried at flat 40.0 hrs at every store. Network Labor % includes security cost; each store dashboard's own Labor % is payroll-only — deliberately different definitions, not reconciled. Blended $/hr = payroll ÷ worked hours.
WoW baseline: Each store's own W40 (09/28–10/04) actuals, recomputed fresh this cycle on the returns-included basis (not carried forward from a prior dashboard). The W40 network total is restated for the same 3 stores.
Store-level detail: Full per-store detail (roster reconciliation, YoY, heatmap, competitive landscape with Step 15 price/promo depth, category performance) lives in each store's own weekly dashboard file — this rollup is a summary view only. CA stores (La Mesa, Lake Elsinore, HLC Greenfield) removed from the dashboards starting W41 (Brett, 2026-10-12).
