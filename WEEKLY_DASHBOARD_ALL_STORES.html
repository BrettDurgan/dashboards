VII. Methodology Notes
Period: W40, Mon 09/28/2026 – Sun 10/04/2026, all 6 stores, 7/7 days real per store. Generated 2026-10-05.
Net sales: Each store's Net Sales = Σ totalBeforeTax on non-void transactions with returns netted in (Brett, 2026-09-28: standard at every store), deduped by transactionId, from self-pulled Dutchie exports (Pull-DutchieWeek.ps1). CA stores corrected −3h for the export timezone artifact (HLC Sunday-night spill folded back). Network Net Sales is a straight sum across all 6 stores.
Labor: Worked Hours / Payroll Cost from UKG DetailedCalculatedTimeCounters filtered by EIN AND Retail Department Full Path (Step 12) × DetailedRates rate effective on each counter date (Sarah's W40 files); _FLSA Overtime counted; salaried at flat 40.0 hrs at every store. Network Labor % includes security cost; each store dashboard's own Labor % is payroll-only — deliberately different definitions, not reconciled. Blended $/hr = payroll ÷ worked hours.
WoW baseline: Each store's own W39 (09/21–09/27) actuals, recomputed fresh this cycle on the returns-included basis (not carried forward from a prior dashboard).
Store-level detail: Full per-store detail (roster reconciliation, YoY, heatmap, competitive landscape with Step 15 price/promo depth, category performance) lives in each store's own weekly dashboard file — this rollup is a summary view only.
