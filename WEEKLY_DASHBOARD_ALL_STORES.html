VII. Methodology Notes
Data sourceThis rollup aggregates each store's own already-approved, individually-delivered W34 dashboard (Springfield, Northampton, Fyre Ants Easthampton, La Mesa, Lake Elsinore, HLC Greenfield) as the single source of truth. No transaction-level or payroll-level data was independently re-pulled or re-derived for this rollup; all figures trace back to each store's own dashboard build.
Unique Customers (network KPI)A simple sum of each store's own unique-customer count. This is NOT deduplicated for customers who may have shopped at more than one Phat Panda Group location this week — treat as an upper bound / directional figure, not a true network-wide distinct-customer count.
Revenue Mix normalizationCategory bucket names were normalized across stores' own Section IX tables for this network view only (e.g. HLC Greenfield's "Cartridge" → "Vaporizer"; "Accessories" → "Paraphernalia"). Each store's own dashboard keeps its native category naming; only this rollup's Section V normalizes for network-wide comparability.
YoY status by storeSpringfield: fully real (+20.87%). HLC Greenfield: fully real (+3.98%), resolved this cycle via the Treez/device-bridge methodology breakthrough. Northampton (-15.08%), Fyre Ants (-11.58%), La Mesa (-33.24%), and Lake Elsinore (-17.18%) remain [PARTIAL] — a 1-day calendar-boundary offset vs. each store's 2025 comparison source, per the standing network-wide convention.
Security costNorthampton and Fyre Ants Easthampton: $0.00/wk by design (no security line item at either MA location). Springfield, La Mesa, Lake Elsinore, HLC Greenfield: confirmed standing figures, not re-asked or re-flagged per cycle.
