VII. Methodology Notes
Period: Mon 2026-08-10 → Sun 2026-08-16 (W33). Generated 2026-08-17.
Net sales: Sum of each store's self-pulled Dutchie POS API transaction data (Pull-DutchieWeek.ps1), Retail type, isVoid=false, isReturn=false, deduped by transactionId, per that store's individual dashboard.
