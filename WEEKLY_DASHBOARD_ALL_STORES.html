VII. Methodology Notes
Period: Mon 2026-09-14 – Sun 2026-09-20 (W38), all 6 stores. Generated 2026-09-22.
Net sales: Sum of each store's self-pulled Dutchie transaction_line_items export, deduped by transactionId, Net = totalBeforeTax, using transactionDateLocalTime. Each store's figure is taken directly from that store's signed-off worksheet/dashboard for this cycle.
Labor: Worked Hours/Payroll Cost from each store's UKG Counters pull (Retail-department-filtered per that store's standing EIN+Department rule); Security Cost confirmed per store by Brett where applicable. Network totals are simple sums across the 6 stores.
WoW baseline: W37 (09/07/2026-09/13/2026), each store's own approved W37 figures.
Store-level detail: See each store's individual W38 dashboard (WEEKLY_DASHBOARD_<STORE>.html) for day-part heatmaps, roster detail, competitive landscape, and category performance — this rollup is a network-level summary only.
