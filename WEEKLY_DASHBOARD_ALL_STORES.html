VII. Methodology Notes
Period: W37, Mon 09/07/2026 – Sun 09/13/2026, all 6 stores, 7/7 days real per store. Generated 2026-09-14.
Net sales: Each store's Net Sales = Σ totalBeforeTax on non-void, non-return Retail transactions (Sec 2.1 filter), deduped by transactionId, from self-pulled Dutchie exports (Pull-DutchieWeek.ps1). Network Net Sales is a straight sum across all 6 stores.
Labor: Worked Hours/Payroll Cost sourced from UKG DetailedCalculatedTimeCounters (standardized across all 6 stores, no mid-cycle switching) × DetailedRates-System latest effective rate. Network Labor % includes security cost; each store dashboard's own Labor % is payroll-only — these are deliberately different definitions, not reconciled.
WoW baseline: WoW baseline is each store's own W36 (08/31-09/06) actuals, recomputed fresh this cycle (not carried forward from a prior dashboard).
Store-level detail: Full per-store detail (roster reconciliation, YoY, heatmap, competitive landscape, category performance) lives in each store's own weekly dashboard file — this rollup is a summary view only.
