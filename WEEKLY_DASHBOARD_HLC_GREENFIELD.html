XIV. Methodology Notes
Period: Mon 2026-08-03 → Sun 2026-08-09. Generated 2026-08-10.
Net sales: Dutchie transaction_line_items GAP_BACKFILL (HLCGreenfield.xlsx export, spans back to Mar 2026, deduped by transactionId), totalBeforeTax, Retail type, isVoid=false, isReturn=false. Unlike Springfield/Fyre Ants/Northampton this cycle, HLC's Sat 8/8 export was NOT truncated — verified full-day span (00:01–23:59) with no Sales Report supplement needed.
SKU/category net-sales scaling: item totalPrice−totalDiscount (isReturned items skipped) summed per transaction, scaled by (transaction totalBeforeTax / summed item net) so item-level revenue reconciles to real net sales; applied before Section IX and the SKU tables. Residual vs. true totals: 0.03%.
UKG hours: DetailedCalculatedTimeCounters 08/03–08/09 (master all-stores export, filtered to Department Full Path containing "Greenfield"). Regular hours only this cycle (no overtime rows). PTO/VAC/PSL/DFML/Excused excluded.
Staffing heatmap: UKG DetailedHours (master all-stores export, punch-level Start/End, filtered to Greenfield), allocated into 4 day-part windows (Morning 9a–11a, Midday 11a–3p, Afternoon 3p–6p, Evening 6p–10p/close per this store's own hours), overlapped against transactionDateLocalTime sales in the same windows. Color mapping flipped this cycle to match Springfield/Fyre Ants/Northampton: neon = below this store's own weekly avg $/labor-hr (understaffed), ember = above avg (slack).
Security: $2,016.00/wk, confirmed by Brett this cycle (down from W31's $2,066.00/wk), split proportional to daily worked hours.
